# זיכרון פרויקט בין סשנים

מטרת התיקייה היא לאפשר לסשן חדש להמשיך מתוך קובצי Git בלבד. ההנחיות המחייבות נמצאות ב־[AGENTS.md](../../AGENTS.md).

## מה לקרוא

- [מצב הפרויקט](project-state.md) — תמונת המצב האחרונה ומה נדרש בהמשך.
- [יומן הסשנים](session-log.md) — מה שונה ונבדק, עם מקורות וקבצים רלוונטיים.
- [מדריך המעבר לתכנון](../../docs/planning-handoff.md) — סדר הקריאה והגבול בין אפיון לתכנון טכני.

הקבצים הם Markdown רגיל, נגישים לכל כלי. עצם קיומם אינו גורם לכלי לטעון אותם אוטומטית; `AGENTS.md` מנחה את הסוכן לקרוא אותם בתחילת העבודה.

## איך לעדכן

אחרי שינוי משמעותי מעדכנים את המצב הנוכחי ומוסיפים רשומה קצרה ליומן. כותבים עובדה, מקור ומועד, ומפרידים בין הושלם, טרם בוצע והצעה. אם מידע ישן כבר אינו נכון, מתקנים את תמונת המצב; היסטוריית Git והיומן שומרות את ההקשר.

תבנית לרשומת סשן:

```text
תאריך:
מטרת הסשן:
בוצע וקבצים ששונו:
החלטות ומקורן:
בדיקות שבוצעו ותוצאות:
לא נבדק / מגבלה:
המשך:
```

לנושא מתמשך אפשר להוסיף קובץ ולרשום אותו באינדקס הזה. אין צורך בקובץ חדש לכל שאלה או פקודה. אין לשכפל כאן את האפיון המלא; מפנים לסעיף המקורי כדי למנוע שתי גרסאות של אותה דרישה.

## מה אסור לשמור

אין לשמור נתוני חיילים אמיתיים, פטורים או נימוקי אילוצים, מספרים אישיים, פרטי קשר, סיסמאות, אסימונים, קודי כניסה/שחזור או מפתחות הצפנה. אין לשמור תמלילי צ׳אט ופלטי כלים גולמיים. שמור מידע על המוצר והעבודה עליו, לא את המידע שהמוצר ינהל בעתיד.
