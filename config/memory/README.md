# זיכרון פרויקט בין סשנים

התיקייה מאפשרת לסשן חדש, של אדם או של סוכן, להמשיך מתוך Git בלבד. אין לה טעינה אוטומטית: [AGENTS.md](../../AGENTS.md) מנחה לקרוא אותה בתחילת העבודה. הזיכרון מסכם; הדרישות נשארות ב[אפיון](../../docs/duty-management-prd.md) וב[יומן ההכרעות](../../docs/open-decisions.md).

## הקבצים

- [מצב הפרויקט](project-state.md) — מה פעיל, מה פתוח, המלצות שטרם הוכרעו והערות תפעול. מתעדכן בכל שינוי משמעותי; מה שהתיישן נמחק ממנו.
- [יומן הסשנים](session-log.md) — רשומה קצרה לכל סשן, החדשה למעלה.

## איך מעדכנים

אחרי שינוי משמעותי מעדכנים את המצב ומוסיפים רשומה ליומן. כותבים עובדה, מקור ותאריך, ומפרידים בין מה שהושלם, מה שלא נבדק ומה שהוא הצעה. רשומת יומן:

```text
## <תאריך> — <נושא>

- מה השתנה וקבצים עיקריים
- החלטות ומקורן (מספר הכרעה)
- בדיקות שרצו בפועל ב־Docker ותוצאתן
- מה לא נבדק, ומה ההמשך
```

כשהיומן מתארך, מסירים רשומות ישנות שכבר אינן נחוצות לעבודה השוטפת; Git שומר אותן. נושא מתמשך יכול לקבל קובץ משלו, שנרשם כאן.

## מה אסור לשמור

נתוני חיילים אמיתיים, פטורים או נימוקי אילוצים, מספרים אישיים, פרטי קשר, סיסמאות, אסימונים, קודי כניסה או שחזור ומפתחות. גם לא תמלילי צ׳אט או פלטי כלים גולמיים.
