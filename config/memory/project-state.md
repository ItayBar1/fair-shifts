## כללים ותלויות

הוראת המשתמש מ־28.09.2026: להמשיך במימוש ולגבות באופן שוטף באמצעות commit ו־push. Husky ‏9.1.7, ‏lint-staged ‏17.6.0 ו־Prettier ‏3.9.9 נוספו. לפני כל commit נבדק תוכן ה־index במלואו ב־Docker מבודד, כולל E2E. ה־hook הותקן ונבדק עם בדיקה זמנית שנכשלה: commit נחסם, והבדיקה הזמנית הוסרה. אין לעקוף את הבדיקה. מ־29.09 ה־hook פועל גם מתוך git worktree; בכל worktree חדש מריצים קודם `sh scripts/install-hooks.sh`, אחרת Git מדלג על הבדיקה בלי הודעה.

ההיקף מלא. מתנדב לפני שחרור פטור מאישור רק בשל הקרבה לשחרור; חסימות אחרות ואישור אחרי התחלה נשארים. אין פיילוט אמת לפני מלוא הגרסה ותנאי ההפעלה. ערכי יחידה בידי האחראים; ספקים, דומיין וסודות מחוץ למאגר.
