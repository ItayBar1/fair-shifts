# מצב הפרויקט

עדכון: 25.09.2026 · שלב: מסירת אפיון לתכנון מימוש.

## מה קיים

- אפיון 1.3 בעברית: 64 סיפורי משתמש, שמונה תחומי מערכת ו־52 תרחישי קבלה מתוכננים.
- יומן שמכסה את כל המספרים 1–145, כולל החלטות שהוחלפו והבהרות; מפת כיסוי גם לדרישות שנמסרו ללא מספר.
- נספח מחקר לדרגות, מייל וגיבוי. פז״ם יוצר התראה לאחראי; אין קידום אוטומטי לפי זמן בלבד.
- `AGENTS.md`, התיקייה הזאת ומדריך מעבר לתכנון, כדי שלא תידרש גישה לצ׳אט.

אין עדיין תוכנית מימוש מפורטת, יישום, סכמת מסד, migrations, חשבונות ספקים מחוברים, סביבת שרת או בדיקות מערכת שרצו. תרחישי הקבלה הם דרישות לבדיקה עתידית, לא תוצאות בדיקה.

## מה הבא

להכין תוכנית מימוש מתוך הקבצים האלה: שלבים שאפשר לבדוק מקצה לקצה, תלויות, גבולות תחומים, סכמת נתונים, חוזי פעולות ואסטרטגיית בדיקות. לשמר את כל התכולה המאושרת ולמפות כל שלב לדרישות ולתרחישי הקבלה.

הטכנולוגיות שאושרו: TypeScript, Next.js, עובד Node.js, PostgreSQL, Docker על Linux פרטי ו־Cloudflare Tunnel. ספק המייל ההתחלתי Brevo Free. גיבוי Google Drive יומי מוצפן, עד 30 עותקים בכפוף לנפח ובדיקת שחזור רבעונית. אין צורך לבחור אותן מחדש.

## השלמות שאינן חסימה לכתיבת התוכנית

האחראים יזינו את ערכי היחידה: מחירון, חלונות זמן ומנוחה, פטורים, כשירויות, דרגות ופז״ם, מועדי שירות ויתרות. אין להמציא ערכי אמת. המנהל הטכני ישלים שרת, דומיין, חשבונות מייל/Google, הרשאות וסודות מחוץ למאגר, בדיקת גיבוי והסדרת ההפעלה. פרטי ספריות, גרסאות, ORM וסכמת מסד הם החלטות תכנון שטרם התקבלו.

אין להסתמך על נתיבי Windows, תיקיות עבודה או תשתית כלים מהסשן המקורי. כל הקבצים הדרושים להגדרת המוצר נמצאים במאגר.
