# קונפיגורציה ותיעוד עבודה

התיקייה מרכזת מידע פרויקטלי מתמשך: [זיכרון בין סשנים](memory/README.md) ו־`security-exceptions.json`, שבו מתועדות חריגות זמניות מאושרות לשער שרשרת האספקה. כללי החריגה ב[מסמך האבטחה](../docs/security.md).

קובצי התצורה האמיתיים של production נשמרים מחוץ למאגר, לפי [מדריך ההפעלה](../docs/operations.md). אין להוסיף לכאן נתוני משתמשים, קובצי סביבה, מפתחות או פרטי חיבור.
