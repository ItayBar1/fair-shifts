# Fair Shifts

מערכת מתוכננת לניהול וחלוקת תורנויות ביחידה, עם לוח משותף, אילוצים ופטורים, שיבוץ לפי טבלת צדק, החלפות והתראות.

המאגר נמצא בשלב אפיון; טרם נבנה יישום.

- [אפיון המוצר המלא — גרסה 1.2](docs/duty-management-prd.md): 64 סיפורי משתמש, שמונה תחומי מערכת ו־50 מקרי קבלה לפיתוח.
- [גרסת HTML לקריאה בדפדפן](docs/duty-management-prd.html): יש להוריד/לפתוח את הקובץ בדפדפן; GitHub מציג את המקור.
- [יומן הכרעות 79–145](docs/open-decisions.md): כל ההכרעות נסגרו, כולל חידוד מנגנון הדרגות לתזכורת פז״ם ואישור אחראי.
- [מקורות וממצאי מחקר](docs/research-notes.md): דרגות, Brevo חינמי וגיבוי Google Drive.

הכיוון הטכני שאושר: TypeScript, Next.js, עובד Node.js ו־PostgreSQL, בקונטיינרי Docker על Linux פרטי דרך Cloudflare Tunnel.

אין לשמור במאגר נתוני חיילים, סיסמאות או מפתחות ספקים. הגדרות היחידה ופרטי ההפעלה יוזנו במסגרת ההקמה.
