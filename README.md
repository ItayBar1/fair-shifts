# Fair Shifts

מערכת מתוכננת לניהול וחלוקת תורנויות ביחידה של כ־120 חיילים, עם לוח משותף, אילוצים ופטורים, שיבוץ לפי טבלת צדק, החלפות והתראות.

## מצב הפרויקט

המאגר נמצא אחרי השלמת אפיון ובדיקת כיסוי, ומוכן לתכנון המימוש. אין עדיין יישום או תוכנית פיתוח מפורטת. אפשר להמשיך מתוך קובצי Git בלבד, ללא הצ׳אט המקורי.

## התחלה בסשן חדש

1. [AGENTS.md](AGENTS.md) — הוראות העבודה ומקורות האמת.
2. [מצב הפרויקט בזיכרון](config/memory/project-state.md).
3. [מעבר מאפיון לתוכנית מימוש](docs/planning-handoff.md).
4. [אפיון המוצר — גרסה 1.3](docs/duty-management-prd.md): 64 סיפורי משתמש, שמונה תחומי מערכת ו־52 תרחישי קבלה מתוכננים.
5. [יומן הכרעות 1–145](docs/open-decisions.md) ו[מפת כיסוי הדרישות](docs/requirements-coverage.md), כולל הבהרות ודוגמאות מהראיון.

מסמכי עזר: [מקורות ומחקר](docs/research-notes.md) ו[גרסת HTML לקריאה](docs/duty-management-prd.html). GitHub מציג קוד HTML; לקריאה יש לפתוח את הקובץ בדפדפן. Markdown הוא המקור המחייב.

## זיכרון בין סשנים

[config/memory](config/memory/README.md) מכילה תמונת מצב ויומן סשנים, המתעדכנים לצד השינויים ב־Git. היא אינה נטענת אוטומטית ואינה מחליפה את האפיון. הוראות הקריאה והתחזוקה ב־AGENTS.md וב־README של התיקייה.

## כיוון הפיתוח שאושר

TypeScript, Next.js, עובד Node.js ו־PostgreSQL; קונטיינרי Docker על Linux פרטי דרך Cloudflare Tunnel. ספק מייל התחלתי Brevo Free עם ניהול מכסה; גיבוי Google Drive ייעודי מוצפן. פרטי התכנון בסעיפים 7–8 באפיון.

טרם נקבעו פקודות התקנה, פיתוח ובדיקות יישום. הן יתועדו עם הקמת הקוד. תרחישי הקבלה במסמך אינם בדיקות שכבר מומשו או עברו.

אין לשמור במאגר נתוני חיילים, סיסמאות, אסימונים או מפתחות ספקים. האחראים יזינו ערכי יחידה בהקמה, והמנהל הטכני ישלים חיבורי תשתית מחוץ למאגר.
