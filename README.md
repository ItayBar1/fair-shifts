גרסה 1.1 מעדכנת את מונח האוכלוסייה השלישית לקמ״א — קצין מקצועי אקדמי — ומוסיפה דרגה נוכחית לחייל, עדכונה והתאמת תורנויות לפי דרגה.

האפיון כולל 56 סיפורי משתמש, שמונה תחומי מערכת ו־36 מקרי קבלה. החלטות שניתנו בראיון מובחנות מהמלצות המימוש ומהשלמות שטרם הוכרעו. הרשימה המרוכזת כוללת גם המלצות מפרקי האמצע ולא רק מסעיף ההשלמות.

בשלב זה המאגר מכיל מסמכים בלבד. תוצאות בדיקות תוכנה או תאימות משפטית אינן נטענות; מקרי הקבלה הם בסיס לפיתוח העתידי.

## עדכון החלטות

לאחר הכרעה יש לעדכן את ההחלטה באפיון, את מצבה ברשימת ההכרעות ואת מקרי הקבלה הרלוונטיים. הגרסה הקריאה ב־HTML משקפת את אותו תוכן של מסמך ה־Markdown.
